# Escalonamento_Sistemas_Operacionais

Projeto desenvolvido para a disciplina de Sistemas Operacionais, com o objetivo de demonstrar o funcionamento de diferentes algoritmos de escalonamento de CPU.

O programa simula a execução de processos utilizando diferentes políticas de escalonamento. Os resultados são exibidos em uma interface gráfica e representados visualmente por meio de um gráfico de Gantt.

# Algoritmos Implementados
FCFS (First Come, First Served)
SJF (Shortest Job First)
Prioridade
Round Robin

# Funcionalidades
Simulação de diferentes algoritmos de escalonamento.
Cálculo do tempo de espera médio.
Cálculo do tempo de retorno (Turnaround).
Interface gráfica desenvolvida com Tkinter.
Exibição de gráfico de Gantt utilizando Matplotlib.
Comparação dos resultados entre os algoritmos.

# Tecnologias Utilizadas
Python
Tkinter
Matplotlib
